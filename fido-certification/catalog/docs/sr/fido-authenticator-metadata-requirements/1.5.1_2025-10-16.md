# FIDO Authenticator Metadata Requirements

Version 1.5.1 · Final Document · 2025-10-16 · **ACTIVE, no expiry (L3/L3+)** · [source](https://fidoalliance.org/specs/fido-security-requirements/fido-authenticator-metadata-requirements-v1.5.1-fd-20251016.html)

## Summary

v1.5.1 (Final, 2025-10-16) of the Metadata Requirements, issued with SR v1.5.1 for the CTAP 2.1 / L3/L3+ track. It lists the mandatory functional, security and biometric metadata fields verified during certification. Apart from the version number, its text matches v1.6. It does not have the multi-device and FIPS fields added in v1.7. Status: ACTIVE with no expiry.

**Who needs it:** vendors certifying against SR v1.5.1, FIDO-accredited security labs

- Mandatory functional fields → Functional Metadata Fields `#functional-metadata-fields`
- Mandatory security fields → §3 `#h2_security-metadata-fields`
- Biometric fields → §4 `#h2_biometric-metadata-fields`
