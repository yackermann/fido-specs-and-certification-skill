# FIDO UAF Registry of Predefined Values

Version 1.1 · Proposed Standard · 2017-02-02 · [source](https://fidoalliance.org/specs/fido-uaf-v1.1-ps-20170202/fido-uaf-reg-v1.1-ps-20170202.html)

## Summary

The 1.1 edition of the UAF Registry of Predefined Values, the version FIDO lists for certification. It defines the UAFV1TLV assertion scheme name, the UAF protocol tags (including TAG_ATTESTATION_BASIC_FULL, TAG_ATTESTATION_BASIC_SURROGATE and TAG_ATTESTATION_ECDAA at 0x3E07–0x3E09), two untagged extensions (Android SafetyNet and Android Key Attestation) and the UAF Secure Element applet AID. Compared with 1.2, it lacks the user verification method, user ID, user verification caching, resident key and attestation conveyance extensions, and the APCV1CBOR tags.

**Who needs it:** authenticator vendors, ASM/client developers and server developers targeting UAF 1.1

**Look here for:**
- Protocol tag values → §4.1 `#h3_tags-used-in-the-protocol`
- Android Key Attestation extension → §5.2 `#h3_android-key-attestation`
- UAF applet AID → §6.1 `#h3_fido-uaf-application-identifier-aid`
