# CTAP 2.1 Errata

Version 2.1 · Proposed Standard · 2022-06-21 · [source](https://fidoalliance.org/specs/fido-v2.1-ps-20210615/fido-client-to-authenticator-protocol-v2.1-errata-20220621.html)

## Summary

This is the FIDO Alliance errata list for CTAP 2.1, dated 2022-06-21. For each correction it gives the affected section of the 2021-06-15 CTAP 2.1 Proposed Standard, the reason for the change, and the original and corrected text side by side. It has three entries:

- NFC user presence (spec §5 Terminology): adds a defined error response when the platform sends a zero-length pinUvAuthParam. The authenticator returns CTAP2_ERR_PIN_NOT_SET or CTAP2_ERR_PIN_INVALID and does not consume the NFC userPresent flag. This keeps multi-authenticator CTAP 2.0 platforms working.
- getInfo option IDs (spec §6.4): fixes the wording and links around userVerificationMgmtPreview and related options.
- PRF values (spec §6.5.8): drops the authenticatorClientPIN row and revises the bioEnrollment and credentialManagement input patterns.

The same corrections are already merged into the CTAP 2.1 errata edition (`fido-client-to-authenticator-protocol`, version `2.1-errata`). Use this list to see exactly what changed, and use the errata edition as the normative text.

**Who needs it:** authenticator vendors and labs checking CTAP 2.1 implementations against corrected behaviour, platform developers handling NFC authenticators
