# Credential Exchange Format

Version 1.0 · Proposed Standard · 2025-08-14 · [source](https://fidoalliance.org/specs/cx/cxf-v1.0-ps-20250814.html)

## Summary

Credential Exchange Format 1.0 (August 2025) is the first Proposed Standard of the JSON/CDDL data model for exporting and importing credentials between providers. It covers accounts, collections and items holding passkeys, passwords, TOTP, keys, payment cards, identity documents and more. It does not specify transport; the Credential Exchange Protocol (CXP) does that. A 2026-03-09 errata edition supersedes it. That edition changes only the Appendix A example payload and one reference. CXF has no FIDO certification program.

**Who needs it:** credential provider and platform developers implementing credential import/export

**Look here for:**
- Credential data types → §3.3 `#sctn-credential-data-types`
- Passkey dictionary → §3.3.12 `#dict-passkey`
- Validating received files → §5.2 `#sctn-validation-of-files`
- Example payload (corrected in the errata edition) → Appendix A `#appendix-a`
