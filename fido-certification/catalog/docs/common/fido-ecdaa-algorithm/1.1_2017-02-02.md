# FIDO ECDAA Algorithm

Version 1.1 · Proposed Standard · 2017-02-02 · [source](https://fidoalliance.org/specs/fido-uaf-v1.1-ps-20170202/fido-ecdaa-algorithm-v1.1-ps-20170202.html)

## Summary

Copy of the FIDO ECDAA Algorithm shipped with the UAF 1.1 suite, and the earliest catalogued version. It defines the elliptic-curve Direct Anonymous Attestation scheme that UAF authenticators can use instead of basic attestation: an issuer-run Join, an authenticator-side Sign (optionally split with the ASM or a TPM) and server-side Verify, plus curves, algorithm names and the signature format. The 1.2 copy is textually the same apart from headers and formula typesetting. FIDO2/WebAuthn no longer use ECDAA.

**Who needs it:** UAF authenticator vendors and FIDO server developers working against the UAF 1.1 suite
