# FIDO Registry of Predefined Values

Version 1.1 · Proposed Standard · 2017-02-02 · [source](https://fidoalliance.org/specs/fido-uaf-v1.1-ps-20170202/fido-registry-v1.1-ps-20170202.html)

## Summary

Copy of the FIDO Registry of Predefined Values shipped with the UAF 1.1 suite, and the earliest catalogued version. It defines the bit-flag and numeric constants UAF uses for user verification methods, key protection, matcher protection, attachment hints, transaction-confirmation displays, signature algorithms and public key formats. The 1.2 copy is the same apart from headers and references. There is no attestation-type section yet.

**Who needs it:** UAF authenticator vendors and server developers working against the UAF 1.1 suite

**Look here for:**
- Key protection types → §3.2 `#h3_key-protection-types`
- Attachment hints → §3.4 `#h3_authenticator-attachment-hints`
- Signature algorithms → §3.6.1 `#h4_authentication-algorithms`
