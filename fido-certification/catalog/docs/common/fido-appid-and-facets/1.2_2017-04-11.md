# FIDO AppID and Facet Specification

Version 1.2 · Proposed Standard · 2017-04-11 · [source](https://fidoalliance.org/specs/fido-u2f-v1.2-ps-20170411/fido-appid-and-facets-v1.2-ps-20170411.html)

## Summary

Copy of the AppID and Facet specification shipped with the U2F 1.2 suite. It defines AppIDs, FacetIDs for web origins, Android (SHA-1 `android:apk-key-hash:` only) and iOS apps, and the Trusted Facet List that a client fetches from an HTTPS AppID: a JSON object with a single `trustedFacets` array of `version` + `ids` entries. Version 2.1 later added SHA-256 Android FacetIDs, a separate TrustedFacetList dictionary with required members, and an explicit version-matching rule.

**Who needs it:** platform & client developers, relying parties & server developers working against the U2F 1.2 suite

**Look here for:**
- FacetID formats → §3.1.1 `#h4_determining-the-facetid-of-a-calling-application`
- Caller authorization rules → §3.1.2 `#h4_determining-if-a-caller-s-facetid-is-authorized-for-an-appid`
- Trusted Facets JSON structure → §3.1.3 `#h4_trustedfacets-structure`

**Changes from previous version:** Editorial only. The normative text matches 1.1; only the status header, the previous-version link and some reference URLs changed.
