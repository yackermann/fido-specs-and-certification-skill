# FIDO Security Reference

Version 1.1 · Proposed Standard · 2017-02-02 · [source](https://fidoalliance.org/specs/fido-uaf-v1.1-ps-20170202/fido-security-ref-v1.1-ps-20170202.html)

## Summary

Copy of the FIDO Security Reference shipped with the UAF 1.1 suite, and the earliest catalogued version. It sets out the UAF/U2F attack classes, security goals, measures and assumptions, and a numbered threat catalogue covering the client, the authenticator, the relying party, the secure channel, the infrastructure, and second-factor use. The 1.2 copy is the same apart from a scope note about physical attacks and reference updates.

**Who needs it:** certification applicants, labs and vendors working against the UAF 1.1 suite

**Look here for:**
- Attack classification → §3 `#h2_attack-classification`
- UAF security goals → §4 `#h2_uaf-security-goals`
- Threats to the client side → §7.1 `#h3_threats-to-client-side`
