# Credential Exchange Format

Version 1.0 · Proposed Standard (errata edition) · 2026-03-09 · [source](https://fidoalliance.org/specs/cx/cxf-v1.0-ps-errata-20260309.html)

## Summary

The Credential Exchange Format (CXF) 1.0 defines a JSON data model for moving a user's credentials between credential providers, such as password managers and passkey providers. Each export is a header plus accounts, which contain collections and items. Each item carries typed credentials: passkeys, basic auth (username/password), TOTP, API keys, SSH keys, credit cards, identity documents, passports, driver's licenses, Wi-Fi passphrases, notes, files, custom fields and more. Types are given in CDDL. Binary values are base64url. Unknown enumeration values must be tolerated so the format can be extended, and IANA registries cover credential types and extensions. CXF does not define the transport. The companion Credential Exchange Protocol (CXP) does that. CXF also sets rules for an orchestrating party that relays data without implementing CXP. The CX specifications have no FIDO certification program.

This errata edition has no change log. A text comparison with the 2025-08-14 edition shows that the normative sections are unchanged. The corrections are in the Appendix A example payload: the passkey example now uses `hmacCredentials`, `credBlob`, `largeBlob` and `payments` in place of `hmacSecret`, and enumeration values were fixed (`wpa2-personal`, `US-CA`). The File example was also corrected, and one reference was updated.

**Who needs it:** credential provider (password manager / passkey provider) developers, platform vendors implementing import/export

**Look here for:**
- Account / Collection / Item structure → §3.2 `#sctn-entity-data-types`
- Passkey export fields → §3.3.12 `#dict-passkey`

**Changes from previous version:** Editorial and example-only. The Appendix A sample payload was corrected (passkey extension fields, enumeration values, File item), and a WebAuthn reference was updated. No normative changes were found when the texts were compared.
