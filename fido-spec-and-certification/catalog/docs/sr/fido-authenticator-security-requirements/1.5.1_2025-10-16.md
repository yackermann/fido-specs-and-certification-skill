# FIDO Authenticator Security Requirements

Version 1.5.1 · Final Document · 2025-10-16 · **ACTIVE, no expiry; required for L3/L3+ (CTAP 2.1 only, GP FIDO2 SE companion program)** · [source](https://fidoalliance.org/specs/fido-security-requirements/fido-authenticator-security-requirements-v1.5.1-fd-20251016.html)

## Summary

v1.5.1 (Final, 2025-10-16) is titled FIDO Authenticator Security Requirements. It branches from v1.5 and was published after v1.6. Its only listed change is the GlobalPlatform FIDO2 SE companion program at L3/L3+. That program builds on a GP protection profile that is not itself evaluated or certified, but a vendor can base its Security Target on it. This version pairs only with CTAP 2.1. It lacks the v1.6 additions: passkey backup/sync requirements and the PP 0117 companion program.

Status: ACTIVE with no expiry and excluded from the sunset policy (see Certification Policy §10.5.6). FIDO requires it for L3/L3+.

**Who needs it:** vendors seeking L3/L3+ for CTAP 2.1 authenticators, especially secure-element products; FIDO-accredited security labs
