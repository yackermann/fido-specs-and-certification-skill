# FIDO Authenticator Allowed Restricted Operating Environments List

Version 1.5.1 · Final Document · 2025-10-16 · **ACTIVE, no expiry (L3/L3+)** · [source](https://fidoalliance.org/specs/fido-security-requirements/fido-authenticator-allowed-restricted-operating-environments-list-v1.5.1-fd-20251016.html)

## Summary

v1.5.1 (Final, 2025-10-16) of the AROE List, issued with SR v1.5.1 for the CTAP 2.1 / L3/L3+ track. It defines the criteria for an Allowed Restricted Operating Environment and lists the TEE, TPM, secure element, VBS and embedded-MCU technologies with blanket AROE status for L2. Apart from the version number, its text matches v1.6. Status: ACTIVE with no expiry.

**Who needs it:** vendors certifying against SR v1.5.1, FIDO-accredited security labs
