# FIDO Technical Glossary

Version 1.1 · Proposed Standard · 2017-02-02 · [source](https://fidoalliance.org/specs/fido-uaf-v1.1-ps-20170202/fido-glossary-v1.1-ps-20170202.html)

## Summary

Copy of the FIDO Technical Glossary shipped with the UAF 1.1 suite, and the earliest catalogued version. It defines the UAF/U2F vocabulary used across the 2017 specifications: client, server, ASM, AAID, attestation, AppID, facets, user verification and related terms. The 1.2 copy is the same apart from one added entry ("User Presence Check") and reference updates. It was later replaced by the much larger 2.1 common-specs glossary.

**Who needs it:** readers of the UAF 1.1 suite

**Look here for:**
- Definition of a UAF term → §3 `#h2_definitions`
- Scope of the glossary → §2 `#h2_introduction`

## Reading guide

**Use this version when:** you read UAF 1.1 suite (February 2017) documents. Suite: UAF 1.1.

**Differences from 1.2:** the only addition in 1.2 is the "User Presence Check" entry, which 1.1 does not have. Otherwise the text is the same.

**Differences from 2.1 (latest):** the same as 1.2's, plus the missing presence entry. 1.1 has none of the FIDO2-era and certification terms (AAGUID, RP ID, AROE/ROE, TEE, SE, ASP, Enterprise Attestation, …). Its User Verification definition in §3 `#h2_definitions` counts a touch as verification. Read it with that in mind when comparing against current certification language.

**Section by section:** structure as in 2.1 (§2 `#h2_introduction`, §3 `#h2_definitions`); see that page's reading guide.
