# FIDO Technical Glossary

Version 1.1 · Proposed Standard · 2017-02-02 · [source](https://fidoalliance.org/specs/fido-uaf-v1.1-ps-20170202/fido-glossary-v1.1-ps-20170202.html)

## Summary

Copy of the FIDO Technical Glossary shipped with the UAF 1.1 suite, and the earliest catalogued version. It defines the UAF/U2F vocabulary used across the 2017 specifications: client, server, ASM, AAID, attestation, AppID, facets, user verification and related terms. The 1.2 copy is the same apart from one added entry ("User Presence Check") and reference updates. It was later replaced by the much larger 2.1 common-specs glossary.

**Who needs it:** readers of the UAF 1.1 suite

**Look here for:**
- Definition of a UAF term → §3 `#h2_definitions`
- Scope of the glossary → §2 `#h2_introduction`
