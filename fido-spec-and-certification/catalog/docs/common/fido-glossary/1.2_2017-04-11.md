# FIDO Technical Glossary

Version 1.2 · Proposed Standard · 2017-04-11 · [source](https://fidoalliance.org/specs/fido-u2f-v1.2-ps-20170411/fido-glossary-v1.2-ps-20170411.html)

## Summary

Copy of the FIDO Technical Glossary shipped with the U2F 1.2 suite. It defines the core UAF/U2F vocabulary: FIDO Client and Server, ASM, AAID, attestation keys and certificates, AppID and facets, user verification and the authenticator types. It predates the FIDO2-era entries (AAGUID, RP ID, enterprise attestation, operating-environment and other security-certification terms) that 2.1 adds. Wording elsewhere is unchanged from 1.1.

**Who needs it:** readers of the UAF 1.1/U2F 1.2 suites

**Look here for:**
- Definition of a UAF/U2F term → §3 `#h2_definitions`
- Scope of the glossary → §2 `#h2_introduction`

**Changes from previous version:** Adds one definition, "User Presence Check" (the authenticator checks that some user is present and agrees to a generic operation). Otherwise only headers and references changed.

## Reading guide

**Use this version when:** you read the U2F 1.2 / UAF 1.2-era (April 2017) documents and need the definition they relied on. Suite: UAF 1.2 / U2F 1.2.

**Differences from 2.1 (latest):** the structure is the same: one alphabetical §3 Definitions `#h2_definitions`. The term list is about 30 entries shorter. Missing entries include AAGUID, AROE/ROE/REE, Authenticator Model, ASP, Credential, ECDAA, Enterprise Attestation, Execution/Operating Environment, Metadata Service/Statement, RP ID, Secure Element, Security Strength, Side Channel Attack, TEE, Trusted Path and tamper-resistant hardware. The behaviour-relevant differences:
- **User Verification** is defined as the authenticator locally authorizing key use "through a touch, pin code, fingerprint…". So a touch counts as verification here. 2.1 separates presence from verification and requires the user to be identified.
- **User Presence Check** (new in 1.2) means only that some user is present and agrees to a generic operation. 2.1 instead requires an explicit, conscious gesture.
- UPV expands to "UAF Protocol Version" instead of "Unified Protocol Version".

**Differences from 1.1:** adds the User Presence Check entry and nothing else of substance.

**Watch out for:** the Abstract has the same copy-paste error as later versions (it describes Registry constants).

**Section by section:** structure as in 2.1; see that page's reading guide.
