# FIDO Security Reference

Version 1.2 · Proposed Standard · 2017-04-11 · [source](https://fidoalliance.org/specs/fido-u2f-v1.2-ps-20170411/fido-security-ref-v1.2-ps-20170411.html)

## Summary

Copy of the FIDO Security Reference shipped with the U2F 1.2 suite. It analyzes UAF and U2F security: attack classification, UAF security goals (U2F shares them except transaction non-repudiation), measures, assumptions, and a threat catalogue covering the client, the authenticator, the relying party, the TLS channel, the supply chain, and UAF-as-second-factor/U2F. Version 2.1 later broadened it to FIDO2/WebAuthn and roughly doubled the security measures.

**Who needs it:** certification applicants, labs and vendors working against the 2017 suites

**Look here for:**
- UAF security goals → §4 `#h2_uaf-security-goals`
- Security assumptions → §6 `#h2_uaf-security-assumptions`
- U2F/second-factor threats → §7.5 `#h3_threats-specific-to-uaf-with-a-second-factor-u2f`

**Changes from previous version:** Mostly editorial. One normative-adjacent addition: a note that physical attacks on the authenticator, after which the legitimate user keeps using it, are not explicitly covered. Reference URLs were also updated.
