# FIDO AppID and Facet Specification

Version 1.1 · Proposed Standard · 2017-02-02 · [source](https://fidoalliance.org/specs/fido-uaf-v1.1-ps-20170202/fido-appid-and-facets-v1.1-ps-20170202.html)

## Summary

Copy of the AppID and Facet specification shipped with the UAF 1.1 suite, and the earliest catalogued version. It defines the AppID and FacetID concepts, FacetID formats for web origins, Android (SHA-1 APK signing-certificate hash) and iOS apps, the Trusted Facets JSON a client fetches from an HTTPS AppID, and the eTLD+1 rule for which web origins may share an AppID. The 1.2 copy is textually the same apart from headers and references.

**Who needs it:** platform & client developers, relying parties & server developers working against the UAF 1.1 suite

**Look here for:**
- Motivation and app-phishing threat → §2.2 `#h3_avoiding-app-phishing`
- FacetID formats → §3.1.1 `#h4_determining-the-facetid-of-a-calling-application`
- Trusted Facets JSON structure → §3.1.3 `#h4_trustedfacets-structure`
