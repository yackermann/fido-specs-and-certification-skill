# FIDO ECDAA Algorithm

Version 2.1 · Proposed Standard · 2022-05-23 · [source](https://fidoalliance.org/specs/common-specs/fido-ecdaa-algorithm-v2.1-ps-20220523.html)

## Summary

Specifies FIDO ECDAA, an attestation scheme based on elliptic-curve Direct Anonymous Attestation with bilinear pairings over Barreto-Naehrig curves. It lets an authenticator prove its model without a shared or per-device certificate linking its registrations. An ECDAA Issuer, standing for the authenticator vendor and dedicated to one model, runs ECDAA-Join once with each authenticator to give it a credential (A, B, C, D). At registration the authenticator runs ECDAA-Sign over the key registration data and AppID, and the FIDO Server runs ECDAA-Verify with the issuer public key taken from metadata. The document defines byte encodings for big numbers and curve points, the global and issuer parameters, Join and Sign split between an authenticator and ASM or between a TPM and ASM, the verify procedure, the curves and algorithm names (ED256, ED256-2, ED512, ED638), the `ecdaaSignature` format, and notes on key sizes, revocation and performance.

ECDAA is relevant to UAF: UAF 1.2 defines an ECDAA attestation path, and the Registry keeps `ATTESTATION_ECDAA` (0x3E09). FIDO2/WebAuthn no longer use it: WebAuthn Levels 2 and 3 have no ECDAA attestation type.

**Who needs it:** authenticator vendors implementing UAF ECDAA attestation, FIDO server developers verifying it, labs

**Changes from previous version:** Substantive. The scheme is now based on newer DAA work (CamDriLeh16 and CCDLNU2017) instead of the patched CheLi2013 construction. The Join flow changes: the issuer nonce step also returns issuer values (B, sc, yc), and the authenticator's second Join step takes only (A, C), since B and D are already known. The ECDAA Issuer's role as the vendor's per-model attester is spelled out, and the issuer public key identifier `c` is introduced. Other edits are terminology ("ECDAA Issuer") and typo fixes. This version follows the FIDO 2.0 ID of 2018, which is not catalogued.
