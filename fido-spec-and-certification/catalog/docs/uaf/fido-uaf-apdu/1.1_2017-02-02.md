# FIDO UAF APDU

Version 1.1 · Proposed Standard · 2017-02-02 · [source](https://fidoalliance.org/specs/fido-uaf-v1.1-ps-20170202/fido-uaf-apdu-v1.1-ps-20170202.html)

## Summary

The 1.1 edition of the UAF APDU mapping, the version FIDO lists for certification. It covers the Hybrid SE authenticator architecture, UAF applet selection, PIN verification, the `UAF` APDU that carries TLV authenticator commands, status-word mapping and long-APDU handling. Its technical content is the same as 1.2; the later edition only renumbers tables and capitalises one requirement keyword, so implementations built to either edition behave the same.

**Who needs it:** Secure Element authenticator vendors and ASM developers targeting UAF 1.1

**Look here for:**
- Command-to-APDU mapping → §4.2.2.1 `#h5_mapping-between-fido-uaf-authenticator-commands-and-apdu-commands`
- Status word mapping → §4.2.2.2 `#h5_response-message-and-status-conditions-of-an-uaf-apdu-command`
- Long APDUs → §4.3 `#h3_managing-long-apdu-commands-and-responses`
