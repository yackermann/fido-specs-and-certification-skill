# Conformance tools docs: FIDO2/Authenticator/Getting-GetInfo-Snapshot

Source: https://github.com/fido-alliance/conformance-test-tools-resources/blob/main/docs/FIDO2/Authenticator/Getting-GetInfo-Snapshot.md (live text: `python3 scripts/resources.py read ctt-fido2-authenticator-getting-getinfo-snapshot`)

## Summary

How-to for FIDO2 authenticator vendors filling in the `authenticatorGetInfo` field of an MDS3 metadata statement. Get conformance tools version 1.6.32 or later (possibly from the experimental builds), choose "Get GetInfo Snapshot" from the menu, connect the authenticator over USB, NFC or BLE, select it and run Get GetInfo, then paste the resulting JSON into the metadata statement and submit it through the MDS3 portal. The page has no headings and relies on screenshots.
