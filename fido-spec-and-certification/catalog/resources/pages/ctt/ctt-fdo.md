## Summary

A short link list in the conformance-tools repository for FIDO Device Onboard implementers. It points to the FDO 1.1 specification and three open-source implementations: Intel/LF Edge's Protocol Reference Implementation, FIDO's own reference implementation and conformance test suite (iot-fdo-conformance-tools), and Red Hat's Rust implementation. It also lists background articles (FIDO, Red Hat, LF Edge, IBM) and a Pre-Interop folder for interop-event preparation.
