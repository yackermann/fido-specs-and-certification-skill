# Authenticator Level 1+

Source: https://fidoalliance.org/certification/authenticator-certification-levels/authenticator-level-1-2/ (live text: `python3 scripts/resources.py read authenticator-level-1-2`)

## Summary

Despite the URL slug, this page covers Authenticator Level 1+ (L1+), not L2. L1+ is for software authenticators that protect keys with white-box cryptography and similar software techniques instead of an AROE, and that are meant to hold up even if the OS is compromised. A FIDO Accredited Security Laboratory evaluates the L1+ Vendor Questionnaire and runs penetration testing; the vendor picks the lab and pays it directly.

The next steps depend on the starting point. Clients and servers only do Functional Certification. A new authenticator does Functional Certification first. An authenticator that is already functionally certified needs no new interop testing and goes straight to the security evaluation. All L1+ applicants need a certification account. As of the snapshot the page lists FIDO certification fees (member/non-member, derivative, delta), which must be paid before the certificate is issued; FIDO charges nothing for the lab evaluation itself.
