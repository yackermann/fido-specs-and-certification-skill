# Biometric Certification

Source: https://fidoalliance.org/certification/biometric-component-introduction/ (live text: `python3 scripts/resources.py read biometric-component-introduction`)

## Summary

Introductory page for the FIDO Biometric Component Certification Program, which has accredited labs test biometric subcomponents for recognition performance and Presentation Attack Detection (PAD). It is mainly a pitch: it explains that vendors can certify once and reuse the third-party result with many customers instead of repeating per-customer evaluations, and lists benefits for biometric vendors and for service providers (independent validation, ISO-aligned evaluation, a FIDO annex in ISO standards). It notes that the program complements the Identity Verification programs (Face Verification and Document Authenticity) and links to the Get Certified page for the actual process; no steps, fees or requirement versions are given here.
