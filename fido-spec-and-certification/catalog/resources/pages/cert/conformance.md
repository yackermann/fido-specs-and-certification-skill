# Conformance Self‐Validation Testing

Source: https://fidoalliance.org/certification/functional-certification/conformance/ (live text: `python3 scripts/resources.py read conformance`)

## Summary

Explains the mandatory conformance self-validation step of FIDO Functional Certification. Vendors run the UAF, U2F and FIDO2 conformance tools (available after accepting the tool request agreement) during development and then mark a run as official so its results are recorded. The Certification Secretariat must confirm official results at least 14 days before an interoperability event, and all tests, including metadata service tests, must pass before attending.

A Vendor ID, requested once per company, is needed only for UAF authenticators; U2F implementations, UAF servers and clients, and all FIDO2 implementations do not need one. The text is the same as the conformance part of the server process page.
