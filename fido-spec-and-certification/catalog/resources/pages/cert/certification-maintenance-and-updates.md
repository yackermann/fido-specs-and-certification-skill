# Certification Maintenance and Updates

Source: https://fidoalliance.org/certification/certification-maintenance-and-updates/ (live text: `python3 scripts/resources.py read certification-maintenance-and-updates`)

## Summary

Explains what happens when a vendor changes an already certified authenticator (patch, new feature, guidance update, hardware or software change). The vendor files a FIDO Impact Analysis Report (FIAR) through the Implementer Dashboard; the Security Secretariat checks it for completeness and classifies the change as non-interfering, minor or major.

Each class maps to a path: non-interfering leads to Derivative certification (an addendum to the existing certificate); minor leads to Delta certification (Secretariat reviews VQ updates for L1, an accredited lab re-tests the delta and updates the FER for L1+ and above); major leads to Recertification with a new certificate, reusing earlier results where possible. The page lists the submission items for each path: FIAR, self-conformance results, interoperability testing (Delta and Recertification only), the Certification Request Form, and a full VQ for Recertification.
