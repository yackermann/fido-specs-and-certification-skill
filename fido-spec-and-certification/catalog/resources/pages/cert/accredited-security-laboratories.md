# FIDO Accredited Security Laboratories

Source: https://fidoalliance.org/certification/authenticator-certification-levels/accredited-security-laboratories/ (live text: `python3 scripts/resources.py read accredited-security-laboratories`)

## Summary

Describes how a security lab becomes FIDO-accredited to run the security evaluations needed for Authenticator Level 1+ and above. It is aimed at labs, not vendors; the list of accredited labs itself is on a separate page. The steps are: review the Security Laboratory Accreditation Policy (v1.1) and submit the application form; if approved, hold an onboarding call with the Security Secretariat; sign the legal agreements; complete training and knowledge testing; then pay the fees, open evaluator accounts and request the accreditation certificate.

A lab needs an ISO/IEC 17025 accreditation for crypto/security or Common Criteria testing, plus at least one accepted third-party accreditation (as of the snapshot: CC, FIPS 140-2/NVLAP, CCTL, GlobalPlatform TEE, TCG TPM, EMVCo or China ISCCC). Fees are on a separate page.
