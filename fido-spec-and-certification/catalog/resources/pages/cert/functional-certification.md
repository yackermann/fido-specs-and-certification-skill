# FIDO Functional Certification Program

Source: https://fidoalliance.org/certification/functional-certification/ (live text: `python3 scripts/resources.py read functional-certification`)

## Summary

An overview of the FIDO Functional Certification programme, which is open to members and non-members, for vendors certifying authenticators, clients or servers. It lists the steps in order: sign the certification NDA (one per company, valid five years across all programmes, and required before anything else), run conformance self-validation with the test tools, pass interoperability testing at a proctored or on-demand event, complete at least L1 Authenticator Certification (authenticators only), and submit the certification request. Two further steps are optional: signing the trademark licence to use the FIDO Certified logo, and registering with the Metadata Service (recommended). Questions go to the certification secretariat by email. The policy document itself is linked from the Getting Started page.
