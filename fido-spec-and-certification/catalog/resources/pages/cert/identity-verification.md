# Identity (IDV) Verification Certification

Source: https://fidoalliance.org/certification/identity-verification/ (live text: `python3 scripts/resources.py read identity-verification`)

## Summary

A landing page for FIDO's remote identity verification (IDV) certifications, aimed at technology providers. It describes two programmes. Document Authenticity (DocAuth) checks that a solution can validate government-issued ID documents. Face Verification checks "selfie" matching against an ID photo, including liveness and bias testing. Both are based on ISO standards and tested by FIDO Accredited Laboratories. Certified providers can be listed in the certified products database, use FIDO logos under agreement, and receive a certificate. Most of the page is marketing about benefits.

Note that the page calls DocAuth "Document Authentication" in one place, and its FAQ link points to the biometric component FAQ.
