# Face Verification Resource Documentation Resource Documentation for Face Verification

Source: https://fidoalliance.org/certification/identity-verification/face-verification/resource-documentation/ (live text: `python3 scripts/resources.py read face-verification-resource-documentation`)

## Summary

The document set for Face Verification (IDV-Face) certification, as of the snapshot. It contains the certification policy (process and recertification), the vendor NDA, the requirements and test procedures (FIDO Biometric Certification Requirements v4.1 for face verification), and a test plan template.

There are a few inconsistencies. The policy is labelled "Face Verification Certification Policy v1.0" but links to the Biometric Component Certification Policy v1.5. The NDA blurb talks about document-reader vendors, apparently copied from the DocAuth page. The "test plan template" link opens an evaluation report template (FBERT v1.5).

**Look here for:**
- Which requirements version applies to face verification? → FIDO Face Verification Requirements `#fido-face-verification-requirements`
- What governs the process and recertification? → FIDO Face Verification Certification Policy `#fido-face-verification-certification-policy`
- Which NDA must I sign? → FIDO Face Verification Vendor NDA `#fido-face-verification-vendor-nda`
- Is there a test plan or report template? → FIDO Face Verification Test Plan Template `#fido-face-verification-test-plan-template`
