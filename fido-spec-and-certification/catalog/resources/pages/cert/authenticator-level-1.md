# Authenticator Level 1

Source: https://fidoalliance.org/certification/authenticator-certification-levels/authenticator-level-1/ (live text: `python3 scripts/resources.py read authenticator-level-1`)

## Summary

Explains Authenticator Certification Level 1 (L1), the baseline security level against basic, at-scale attacks. At least L1 is required for UAF, U2F and FIDO2 authenticator certification. The page describes four typical L1 authenticator architectures, from an app on a high-level OS with no isolation through to a fully AROE-based design. Levels apply only to authenticators, so clients and servers take Functional Certification.

New implementations start with Functional Certification. Some L1 test procedures are checked during interoperability testing, and then the Authenticator Certification Policy process follows. Already certified authenticators repeat functional certification so the proctor can check the L1 procedures. In both cases the FIDO Security Secretariat evaluates the L1 Vendor Questionnaire, and a certification account is required. Fees are charged per implementation and paid before the certificate is issued. The amounts are on linked pages.
