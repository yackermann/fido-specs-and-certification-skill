# Resource Documentation FDO

Source: https://fidoalliance.org/device-onboarding-overview/device-onboarding-certification/resource-documentation-fdo/ (live text: `python3 scripts/resources.py read resource-documentation-fdo`)

## Summary

A document list for vendors starting FIDO Device Onboard (FDO) certification. The programme is open to non-members, and members get fee discounts and co-marketing. As of the snapshot it links the FDO Security and Privacy Requirements v1.0 (HTML and PDF) with the matching Vendor Questionnaire spreadsheet, the FDO Privacy Policy v1.0, the FIDO Certification NDA and the trademark licence (TMLA) page.

**Look here for:**
- Which security and privacy requirements apply to FDO? → Requirements `#requirements`
- Where is the FDO privacy policy? → Policies `#policies`
- Which NDA and trademark agreements are needed? → Administrative `#administrative`
