# DocAuth Certification Resource Documentation

Source: https://fidoalliance.org/certification/identity-verification/document-authenticity/resource-documentation/ (live text: `python3 scripts/resources.py read document-authenticity-resource-documentation`)

## Summary

Download page for the documents behind FIDO Document Authenticity (DocAuth) certification, aimed at vendors of document validation (document reader) solutions and their labs. As of the snapshot it offers the DocAuth Certification Policy v1.0 (process and recertification rules), the vendor NDA, the DocAuth Requirements (v2.0 active; v1.2 shown as active until a 28 September 2026 sunset; v1.1 deprecated for new evaluations but still usable for delta and derivative maintenance), and a test plan / TOE description template. The v1.2 entry is still labelled active although its stated sunset date precedes the snapshot date, so that label looks stale. The page links on to the DocAuth Get Certified page.

- Which DocAuth requirements version applies? → FIDO Document Authenticity (DocAuth) Requirements `#fido-document-authenticity-docauth-requirements`
