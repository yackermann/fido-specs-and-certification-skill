# FIDO Accredited Laboratories Overview

Source: https://fidoalliance.org/laboratory-overview/ (live text: `python3 scripts/resources.py read laboratory-overview`)
Same content also at: https://fidoalliance.org/certification/identity-verification/document-authenticity/accredited-labs/


## Summary

Short overview of the three kinds of FIDO Accredited Laboratories: security labs that run the security evaluations for Authenticator Certification at Level 1+ and above, biometric labs that test for the Biometric Component Certification programme, and DocAuth labs for Document Authenticity certification. The page embeds a Lab Finder for searching and filtering the accredited labs; the list itself is interactive and not in the page text, so check it live rather than relying on the snapshot.
