# Metadata Submission Terms (for Authenticator Vendors)

Source: https://fidoalliance.org/metadata-submission-terms-for-authenticator-vendors-2/ (live text: `python3 scripts/resources.py read metadata-submission-terms-for-authenticator-vendors-2`)

## Summary

Legal terms an authenticator vendor accepts before uploading Metadata Statements to the FIDO Metadata Service (MDS). They require statements to conform to the Metadata Statement specification (v3.0 is referenced), license FIDO to publish them and build MDS BLOB files from them, let FIDO reject or request fixes to faulty statements, oblige the vendor to watch the BLOB for errors, and set out ownership, permitted use, disclaimers and liability limits; the MDS user-side usage terms are attached as an exhibit.
