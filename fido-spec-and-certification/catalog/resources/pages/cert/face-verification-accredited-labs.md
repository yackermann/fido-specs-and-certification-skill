# Face Verification Accredited Labs

Source: https://fidoalliance.org/certification/identity-verification/face-verification/accredited-labs/ (live text: `python3 scripts/resources.py read face-verification-accredited-labs`)

## Summary

Lists the laboratories accredited to test for Face Verification certification, with contact details, accreditation certificate numbers, issue dates and the programmes each lab covers. As of the snapshot the labs are TÜV Informationstechnik (Germany), TTA (South Korea), Fime Taiwan, Ingenium Biometrics (UK), BixeLab (Australia) and Fime EMEA (France). All of them also cover Biometric Component testing, and all except TÜV also cover DocAuth. The page ends with a link to the Face Verification get-certified steps.

Note that TÜV and Ingenium are shown with the same laboratory certificate number, which looks like a copy error on the page.
