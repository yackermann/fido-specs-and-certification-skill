# Biometric Certification Resource Documentation

Source: https://fidoalliance.org/certification/resource-documentation-biometric/ (live text: `python3 scripts/resources.py read resource-documentation-biometric`)

## Summary

A download index for biometric component certification. It links the Biometric Component Certification Policy, the FIDO Authenticator Metadata Requirements, the certification NDA, the Allowed Integration Document template, and the Biometric Certification Requirements, which cover performance testing and Presentation Attack Detection.

As of the snapshot: Policy v1.5 is active and v1.4 is sunset; Requirements v5.0 and v4.1 are both marked active, with v4.1 due to sunset on 31 March 2027; v3.0 is sunset. The linked v5.0 file is a review draft ("rd02", dated 2026-09-01) even though it is labelled active, and the metadata requirements link is a 2018 working draft.

**Look here for:**
- Which biometric policy and requirements versions are current → Biometric Certification Resource Documentation `#biometric-certification-resource-documentation`
- The NDA and Allowed Integration Document template → Biometric Certification Resource Documentation `#biometric-certification-resource-documentation`
