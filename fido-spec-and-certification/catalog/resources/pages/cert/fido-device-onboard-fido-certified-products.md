# FIDO Certified Device Onboard (FDO) Products

Source: https://fidoalliance.org/certification/fido-device-onboard/fido-certified-products/ (live text: `python3 scripts/resources.py read fido-device-onboard-fido-certified-products`)

## Summary

The public register of implementations certified under the FIDO Device Onboard (FDO) programme. Each entry is a table giving the company, implementation name, FDO specification version, implementation class (Device, Device Onboarding service, Rendezvous server), certification policy version and which component tests were passed. Device-class entries also name the FDO Security and Privacy Requirements version and a security level.

As of the snapshot there are four entries from two companies (ASRock Industrial and VinCSS), all against FDO v1.1 and FDO Certification Policy v1.0; the two device entries are at Level 1 and passed conformance, interoperability and security testing, while the DO and RV server entries list conformance and interoperability only. The policy link points to a drafts.fidoalliance.org working-draft URL.
