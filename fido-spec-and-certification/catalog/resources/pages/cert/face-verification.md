# FIDO Face Verification Certification Program

Source: https://fidoalliance.org/certification/identity-verification/face-verification/ (live text: `python3 scripts/resources.py read face-verification`)

## Summary

A mostly promotional overview of the FIDO Face Verification certification for identity verification. It is aimed at vendors of "selfie match" tools that compare a live face with the photo on a government ID. The certification tests deepfakes, liveness, demographic bias (skin tone, age, gender), biometric matching accuracy and injection attacks. FIDO Accredited Laboratories do the testing, and the programme is presented as a companion to Document Authenticity. Certified products are listed in FIDO's certified-products database and receive a certificate and access to the logo. The page has no process steps, requirement versions or fees; it links to a separate Get Certified page.
