# Get Certified for Biometric Components

Source: https://fidoalliance.org/certification/get-certified-biometric/ (live text: `python3 scripts/resources.py read get-certified-biometric`)

## Summary

Two-step starting point for Biometric Component certification: sign the FIDO certification NDA and send it with a statement of intent to the Biometric Component Secretariat, then pick a FIDO Accredited Biometric Laboratory and contact it to start testing. As of the snapshot the contact address given is the DocAuth secretariat mailbox, which looks like a copy error worth confirming with FIDO.
