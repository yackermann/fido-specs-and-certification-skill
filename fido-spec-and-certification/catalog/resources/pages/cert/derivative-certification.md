# Derivative Certification

Source: https://fidoalliance.org/certification/certification-maintenance-and-updates/derivative-certification/ (live text: `python3 scripts/resources.py read derivative-certification`)

## Summary

Describes derivative certification. It is for OEMs and others certifying many products built on an existing FIDO Certified implementation with the same FIDO implementation and configuration. Derivatives skip interoperability testing and cost less than a base certification (the page gives no amounts). The derivative and base certificate need not belong to the same company. A scenario table shows which cases qualify: reused certified SDKs, modules or servers, and new models with unchanged FIDO parts, do. Cosmetic variants and bug-fix releases need nothing new, and changed FIDO functionality needs full certification.

Several derivatives from one base certificate can go in one registration (bulk). One of them must complete the Derivative Test Plan, and the rest are listed in a bulk template. A submission needs the registration form, the base certificate number, self-conformance results, the Derivative Test Plan, the self-assertion checklist, fees and a FIAR report.
